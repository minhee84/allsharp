## T0 공통 셸 (로그인 제외 모든 화면)

- GNB: 로고 · 기관명 칩 · 통합 검색(Ctrl+K, 초성) · 즐겨찾기 · 매뉴얼 · 지원요청 · 세션 시간 · **출퇴근 상시 버튼** · 사용자
- GNB 화면 설정(슬라이더 아이콘): 드롭다운 패널 360 · 테마 컬러 3안 · 화면 모드 3종(밝게 · 어둡게 · 시스템 설정, 미니 화면 미리보기 — KRDS "기본/선명하게"는 고대비로 오해되어 라벨 변경) · 글자 크기 3단계(보통 100% · 크게 112.5% · 가장 크게 125%) · 초기화/적용 (Figma `Shell/화면 설정 패널`)
- LNB: 아이콘+라벨, 현재 모듈 배경 강조, 접기. 접힘(64): 대메뉴 아이콘만 표시, 하위 메뉴 숨김, 현재 모듈(열린 모듈 포함) 강조, 마우스를 올리면 오른쪽에 메뉴 이름 툴팁, **클릭하면 LNB 를 펼치지 않고 오른쪽에 하위 메뉴 플라이아웃(폭 240, E2)** — 바깥 클릭·Esc·메뉴 선택 시 닫힘, 현재 화면 항목 강조, 하단 버튼은 "메뉴 펼치기" 아이콘. 늘어난 폭은 본문 열이 받고 사이드 열은 360 유지 (Figma `LNB Item` Collapsed=True, `Tooltip`)
- **MDI 탭**: 전체 이름 툴팁, 미저장 ●, 10개 초과 "+N"
- 페이지 헤더: 경로·제목·☆ 왼쪽, 주 액션 오른쪽 끝, 도움말 버튼 → 오른쪽 360 패널
- **상태바**: 조회 건수·저장 결과·오류를 한 위치에서 안내, 토스트는 상태바 위 고정 위치
- 컨텍스트 메뉴: MDI 탭 우클릭(이전/다음 화면·새 창·닫기), 그리드 행·헤더 우클릭
- ALL#_i: 위치·패널 폭 360 고정, 주 액션·상태바를 가리지 않음

### 템플릿별 개선 포인트

**리스트**
- 상세조건 접기: 자주 쓰는 4개만 기본 노출, 나머지는 "상세조건". 펼친 상태는 사용자별로 기억
- 적용 조건 칩: 조회에 쓴 조건을 결과 위에 칩으로 표시, x로 바로 해제
- 버튼 위계: 주요 1 + 보조 2 + 더보기. 엑셀은 그리드 툴바로 이동
- 그리드 툴바: 건수·선택 건수·금액 합계를 그리드 위에 실시간 표시
- 조회/편집 모드: 하나의 템플릿에서 모드 전환. 편집 모드에서 변경된 행은 왼쪽 주황 표시
- 선택 일괄 처리: 행을 선택했을 때만 일괄 처리 바 노출

**분할**
- 방향 전환: 상하/좌우를 옵션으로 전환
- 분할 크기 조절: 분할바를 끌어 비율 조정
- 선택 맥락 표시: 상세 머리에 선택된 건(전표번호·적요·금액) 표시
- 차대 균형 검증: 차변·대변 합계와 균형 여부를 상세 머리에 표시
- 선택 일괄 승인: 체크한 건이 있을 때 선택 바에서 승인

**목록+상세폼**
- 결재 컴포넌트: 결재 단계 표시 + 현재 상태에서 가능한 버튼만 노출
- 목록 접기: 목록을 접으면 상세 작성 영역 확장
- 섹션 내비게이션: 탭 대신 한 화면에 섹션으로 펼치고 왼쪽 목차로 이동
- 예산 가능액 검증: 요청금액 입력 즉시 사용가능액 초과 표시
- 첨부 공통 영역: 끌어다 놓기 첨부 영역을 모든 등록 화면에 같은 형태로 사용
- 하단 고정 저장 바: 변경 여부와 저장 버튼을 하단에 고정

**대상 상세**
- 대상 검색·필터: 목록 위에서 이름·사번 검색과 재직상태 필터
- 프로필 머리: 사진·성명·부서·직급·재직상태·근속을 머리 영역에 요약
- 탭 건수 배지: 탭마다 등록 건수 표시, 빈 탭은 회색
- 변경 감지: 저장하지 않고 다른 대상으로 이동하면 저장/버리기 선택 안내

**계층 코드**
- 계층 열 탐색: 정책 → 단위 → 세부사업을 왼쪽에서 오른쪽으로 따라가는 계층 열
- 열마다 추가: 열 머리에 건수와 추가 버튼만, 저장은 화면 상단 1개
- 속성 패널: 선택한 세부사업의 재원·편성부서를 오른쪽 속성 패널에서 편집
