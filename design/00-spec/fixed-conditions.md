- 우선순위: **가독성 > 정보량 > 심미성**
- 효율 우선(클릭 최소·키보드) · 정보 밀도 유지 · 일관성 · 명확한 상태 · 확장성

- 사용자: 공공기관 행정 실무자, 평균 35세, 하루 대부분 시스템 사용 → 시각 피로 최소화, 대비 4.5:1

## T0 공통 셸 (로그인 제외 모든 화면)

- GNB: 로고 · 기관명 칩 · 통합 검색(Ctrl+K, 초성) · 즐겨찾기 · 매뉴얼 · 지원요청 · 세션 시간 · **출퇴근 상시 버튼** · 사용자
- LNB: 아이콘+라벨, 현재 모듈 배경 강조, 접기
- **MDI 탭**: 전체 이름 툴팁, 미저장 ●, 10개 초과 "+N"
- 페이지 헤더: 경로·제목·☆ 왼쪽, 주 액션 오른쪽 끝, 도움말 버튼 → 오른쪽 360 패널
- **상태바**: 조회 건수·저장 결과·오류를 한 위치에서 안내, 토스트는 상태바 위 고정 위치
- 컨텍스트 메뉴: MDI 탭 우클릭(이전/다음 화면·새 창·닫기), 그리드 행·헤더 우클릭
- ALL#_i: 위치·패널 폭 360 고정, 주 액션·상태바를 가리지 않음

## 공통 규칙

- 버튼: Primary 화면당 1개(오른쪽 끝), 노출 최대 4개, 나머지 더보기, 삭제는 더보기 하단 + 확인창, "동사+대상", 숫자 접미어 금지
- 상태: 색 + 아이콘 + 텍스트 (✓ 승인 · ! 확인 필요 · ✕ 오류·반려 · i 안내 · ✎ 수정됨)
- 데이터: 금액 우측 정렬·천 단위 쉼표·단위는 헤더, 음수·초과는 빨강+부호+아이콘, 빈 값 "—", 개인정보 기본 마스킹, 긴 텍스트 말줄임+툴팁
- 차트: 범주 7개 초과는 정렬 막대(상위 N+기타), 빠진 월도 축에 표시, 진행 중 월 구분, 파이 남용 금지
- 문구: 명사형·존댓말
